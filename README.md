# 용돈기입장 (템플릿)

통장·월급·적금 구조를 내 상황에 맞게 설정해서 쓰는 용돈기입장 웹앱이에요.
빌드 없는 순수 HTML/CSS/JS PWA라서 GitHub Pages에 올리면 바로 쓸 수 있고, 아이폰은 Safari → 공유 → 홈 화면에 추가로 앱처럼 써요.

## 처음 열면
설정 마법사가 열려요. 예시가 채워져 있으니 고치기만 하면 돼요.
1. 통장 (이름 · 종류: 입출금/현금/적금/예금 · 용도 · 색 · 비상금 통장 여부)
2. 월급 · 월급날 · 월급 받는 통장 · 생활비 쓰는 통장 · (선택) 생활비 예산
3. 생활비 입금 ("🏦 생활비 입금!" 버튼을 누르면 월급 통장에서 통장별로 나눠 보내기)
4. 고정지출 (매달 며칠 · 얼마 · 어느 통장에서 → 그 날짜 0시가 지나면 자동 출금 기록)
5. 적금 (어느 통장에서 · 매달 금액 · 첫 납입일 · 회차 · 이미 낸 회차 · 만기일 · 금리)
6. 홈 화면 (사용한 생활비 / 모은 돈 · 비상금 구분 · 내역에서 따로 볼 통장)
7. 분류 (세부 항목 · 두 번째 선택지)
8. 지금 잔액

나중에 ⋯ → 설정하기에서 모두 고칠 수 있어요.

## 데이터
- 모든 기록과 설정은 **내 기기(localStorage)에만** 저장돼요. 서버로 보내지 않아요.
- 설정하기 → 백업에서 기록 + 설정을 파일 하나로 내보내고 불러올 수 있어요.

## 개발
- 파일: `config.js`(설정·날짜·분류) · `legacy.js`(예전 백업 변환) · `data.js`(계산 Store) · `app.js`(화면) · `sheets.js`(월급날·잔액 맞추기·백업) · `form.js`(기록 입력) · `fixed.js`(고정지출 탭 · 생활비 입금) · `chart.js`(분석) · `setup-steps.js` / `setup.js`(설정 마법사)
- 미리보기: `python3 -m http.server` 후 http://localhost:8000
- 계산 검증: `node tests/check.js`
- 파일을 고치면 `sw.js`의 `VERSION`을 올려야 폰에 새 버전이 반영돼요.
